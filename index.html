      How it works: every device connects out to a game relay server over an ordinary secure connection — no phone or computer has to be reachable by another, so guests on cellular or any network can join. The host’s browser is still the dealer — it holds the deck, pot, and turn order — and the relay just carries the messages between the table and the host. That still means if the host closes their tab, the room ends for everyone — but now you’ll see it happen: the host sends a heartbeat about every ten seconds, and if it goes quiet, your screen says so instead of hanging. Keep the host tab open all game night.

      At the table

        House rules — Five Card Draw
        • Deck: 54 cards — the standard 52 plus 2 jokers.
        • Wild: jokers and all deuces (2s) are wild — they can stand for any card.
        • Ante: 10 chips from everyone, every hand.
        • Draw: after the first betting round, discard and draw up to 3 cards.
        • Betting: one round before the draw, one after. Raises in 25 / 50 / 100 steps, max 3 raises a round.
        • Five of a kind is the best hand at this table — wild cards make it possible.

        House rules — Blackjack
        • Pays: blackjack pays 3 to 2. Dealer stands on all 17s.
        • Double down on your first two cards — one card, then stand.
        • Seats play in turn: Don, then you, then Layton. The felt follows the turn.
        • Shoe: four decks, reshuffled when it runs low.
